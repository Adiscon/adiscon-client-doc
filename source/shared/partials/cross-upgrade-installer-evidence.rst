.. rubric:: Representative setup evidence

The screenshots below come from one affected setup run and are representative
of the visual clues described in this article. Product names, component labels,
and version numbers can differ in other product installations.

.. figure:: ../../images/installer-cross-upgrade-old-about.png
   :alt: About dialog showing the installed product before the update
   :width: 100%

   The installed product reports the older client and service versions before
   the update.

.. figure:: ../../images/installer-cross-upgrade-installing.png
   :alt: InstallShield progress window during a product update
   :width: 100%

   The setup wizard can display a normal installation-progress page.

.. figure:: ../../images/installer-cross-upgrade-completed.png
   :alt: InstallShield completion window after a product update
   :width: 100%

   The wizard can report that the installation completed successfully.

.. figure:: ../../images/installer-cross-upgrade-resume.png
   :alt: InstallShield resume window for a product update
   :width: 100%

   A later maintenance action can resume the InstallShield wizard.

.. figure:: ../../images/installer-cross-upgrade-incomplete-features.png
   :alt: InstallShield Custom Setup showing incomplete feature selection
   :width: 100%

   Custom Setup can show an unexpected feature state, such as zero selected
   subfeatures or zero required disk space.

.. figure:: ../../images/installer-cross-upgrade-reinstalling.png
   :alt: InstallShield progress window during file reinstallation
   :width: 100%

   A second maintenance run can reinstall the selected product files.

.. figure:: ../../images/installer-cross-upgrade-reboot-warning.png
   :alt: Installer warning that a reboot may be required
   :width: 100%

   Files or services that remain in use can cause the installer to request a
   reboot.

.. figure:: ../../images/installer-cross-upgrade-new-about.png
   :alt: About dialog showing the newer client and service versions
   :width: 100%

   After a successful file refresh, the client and service report the newer
   versions.

.. figure:: ../../images/installer-cross-upgrade-running.png
   :alt: Product window running after the update
   :width: 100%

   Verify the running product after the installer finishes.
